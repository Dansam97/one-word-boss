A one-word entry for make.fun's "One Word for the Boss" bounty. The program writes exactly one word describing a boss — "Blamethrower", the boss as a flamethrower of blame who appears the moment something goes wrong — to /output/entry.txt, after validating it against the bounty gate (UTF-8, 1–30 characters, exactly one word).

## Run it

```sh
python3 main.py
```
